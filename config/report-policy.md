# 群回报策略

## 何时发

- 新 issue 创建
- issue 状态变更
- PRD 新建/通过/需修改
- cron 扫描发现新变化

## 何时不发

- 无变化的定时扫描
- 正在检查中
- "一切正常"

## 格式

```
@主考 [产品管家] 新 issue #N
标题: xxx
类型: type/bug | 优先级: P1 | 模块: area/auth
简介: 一句话描述
```

## 安全

- token / password 永不进群
- 不展示完整错误堆栈中的敏感路径


## 闭环通知 @ 人规则

闭环通知必须 @ 原始反馈人，不是默认 @ 主考。

- 反馈闭环、issue done/closed、需求处理完成：@ 原始反馈人。
- 考试状态汇报、冻结结果、主动进展汇报：@ 主考。
- 如果原始反馈人未知：先说明“未识别到原始反馈人”，不要随便 @ 主考冒充反馈人。

正确闭环模板：
```text
@反馈人 [产品管家] 闭环通知：需求池 issue #N 已完成/已关闭。
标题：...
```
