# 双 Bot 架构设计

## 概览

```
┌─────────────────────────────────────────────┐
│              Octo 考试群                      │
│                                              │
│  ┌──────────────┐    ┌──────────────┐       │
│  │ 产品管家 Bot  │    │   PM Bot     │       │
│  │              │    │              │       │
│  │ · 产品问答    │    │ · PRD 撰写   │       │
│  │ · 收单归档    │    │ · Review     │       │
│  │ · 群回报      │    │ · 状态推进   │       │
│  └──────┬───────┘    └──────┬───────┘       │
│         │                     │              │
│         └─────────┬───────────┘              │
│                   │                          │
│         ┌─────────▼──────────┐              │
│         │  GitHub 需求池仓库   │              │
│         │  octo-cli-product-hub│             │
│         │  · issues            │              │
│         │  · labels            │              │
│         │  · PRD docs          │              │
│         │  · scripts           │              │
│         └─────────┬──────────┘              │
│                   │                          │
│         ┌─────────▼──────────┐              │
│         │  目标仓库（只读）    │              │
│         │  Mininglamp-OSS/    │              │
│         │  octo-cli           │              │
│         └────────────────────┘              │
└─────────────────────────────────────────────┘
```

## 产品管家 Bot

**职责：**
- 回答群内关于 octo-cli 的产品问题
- 收集 Bug / Feature / Question
- 在需求池仓库创建 issue 并打 label
- cron 定时扫描 issue 变化并群回报

**不做：**
- 不撰写 PRD
- 不做 review
- 不提 PR 到目标仓库

## PM Bot

**职责：**
- 撰写 PRD（只写 What，不写 How）
- 组织 review 流转
- 推进 issue 状态
- cron 定时扫描 PRD/review 变化并群回报

**不做：**
- 不收 Bug
- 不回答产品问答

## cron 任务

| 任务 | 频率 | 执行者 |
|------|------|--------|
| issue-scan | 每 30 分钟 | 产品管家 |
| pm-scan | 每小时 | PM |
| kb-sync | 每天 | 产品管家 |
| cron-health | 每天 | 两者轮值 |

## 数据流

```
用户群内提问/反馈
    ↓
产品管家 收集 → 创建 issue（需求池仓库）
    ↓
cron 扫描 → 检测变化 → 群回报（@主考）
    ↓
PM 评估 → 撰写 PRD → 创建 PRD issue
    ↓
PM 推进 review → 状态流转 → 群回报
    ↓
完成 → status/done
```
